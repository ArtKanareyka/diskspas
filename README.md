# ДискСпас

**Спасаем файлы с Яндекс Диска.** Программа для компьютера: открывается окно в браузере, где за пару кликов
выбираете, что скачать и куда. Она только читает файлы и ничего не меняет и не удаляет в облаке.

Сделана для случая, когда официальный клиент не справляется: сыплет ошибками `502/504`, зависает или бесконечно
перезапускает загрузку, потому что часть серверов хранения Яндекса принимает соединение, но **не отдаёт данные**.

## Как пользоваться

1. Скачайте программу для своей системы на странице [Releases](../../releases) и запустите двойным кликом.
2. В открывшемся окне пройдите пять шагов: **Вход → Что скачать → Куда → Проверка → Загрузка**.
3. Дождитесь окончания. Остановить и продолжить можно в любой момент, прогресс не теряется.

Подробная инструкция с получением токена: [docs/INSTRUCTIONS.md](docs/INSTRUCTIONS.md).

## Что умеет

- **Ссылки «поделиться»:** вставьте `disk.yandex.ru/d/…`, и скачивание пойдёт без токена и входа.
- **Выбор что скачать:** весь Диск или отдельные папки и файлы (дерево с галочками).
- **Выбор куда:** свой обзор папок прямо в окне, создание новой папки, показ свободного места.
- **Не застревает на «больных» файлах.** Если сервер вернул 0 байт или ошибку 500, файл откладывается и
  повторяется позже, а остальные продолжают качаться.
- **Докачка с любого места.** Файлы качаются небольшими кусками, перезапуск почти мгновенный.
- **Сама подбирает скорость:** увеличивает число одновременных загрузок, пока растёт скорость, и сбавляет при перегрузке.
- **Разумный порядок:** сначала фото, видео и документы, потом остальное, в конце служебные и временные файлы
  (их можно не скачивать вовсе).
- **Проверка целостности:** MD5 считается прямо во время скачивания.
- **Понятный прогресс:** скорость, сколько осталось, какие файлы качаются, что ждёт повтора.
- **Пауза, продолжение, остановка** и кнопка «Открыть папку» после окончания.
- **Безопасные имена для Windows:** запрещённые символы и пробелы в конце имён заменяются, длинные пути работают.
- Без внешних зависимостей, без телеметрии. Токен хранится только у вас на компьютере.

> Это обходной путь для нестабильного сервиса, а не замена резервным копиям. Программа не может скачать то, что
> серверы Яндекса отказываются отдавать: такие файлы повторяются, пока Яндекс не восстановится, и попадают в отчёт
> (`<папка>/.diskspas/report.txt`).

## Безопасность

- **Программа работает только на вашем компьютере.** У неё нет своих серверов, поэтому она не может отправить куда-то
  файлы, токен или статистику. Нет рекламы, аналитики и скрытых соединений.
- **Пароль от Яндекса не нужен и не запрашивается.** Вместо него Яндекс выдаёт токен с правом только на чтение
  (`cloud_api:disk.read`): изменить или удалить что-то на Диске с ним нельзя.
- Токен хранится в профиле пользователя с доступом только владельцу, не пишется в логи и отправляется только Яндексу.
- Окно работает по адресу `127.0.0.1` (ваш компьютер) и защищено ключом: другие сайты управлять им не могут.
- **Как проверить самому:** в «Мониторе ресурсов» (вкладка «Сеть») видно, что программа обращается только к серверам
  Яндекса; на странице разрешения Яндекса должно быть только «Чтение всего Диска»; доступ можно отозвать в любой
  момент на <https://id.yandex.ru/security/access>.
- **Не удаляйте файлы из облака, пока не убедились, что копия в порядке.**

## Запуск из исходников и разработка

Нужен Python 3.9 или новее, больше ничего.

```
python -m diskspas            # открыть окно
python -m unittest discover -s tests -v
python tests/run_demo.py      # окно на поддельном Диске (токен для входа: T0KEN)
python scripts/make_icon.py   # пересоздать иконку
```

Тесты работают с локальной заглушкой API и серверов хранения Яндекса, которая умеет отдавать пустой ответ,
HTTP 500, зависания и повреждённые данные.

Сборка одного файла: `pip install pyinstaller`, затем
`pyinstaller --onefile --name DiskSpas --noconsole --icon assets/icon.ico --paths src scripts/entry.py`.
Для релизов это делает CI (`.github/workflows/ci.yml`) по тегу вида `v1.0.0`.
